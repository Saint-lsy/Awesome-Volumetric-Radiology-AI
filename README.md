## **Multimodal Large Language Models (MLLM-based Methods)**

> **Note**
> We categorize MLLM-based radiology methods by the actual visual input form:
> (1) **2D ViT + LLM** for native 2D radiology images such as chest X-ray;
> (2) **3D ViT + LLM** for models that directly ingest volumetric CT/MRI;
> (3) **Hybrid / Serialized Volume + LLM** for models that support both 2D inputs and full 3D studies, including slice-serialization or flattened-volume schemes;
> (4) **Agentic Systems** for tool-augmented or multi-agent medical reasoning frameworks.
